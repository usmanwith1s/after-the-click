# ✨ After the Click

> An interactive, cinematic web experience designed to turn a simple shared link into a memorable surprise.

After the Click is a small interactive web project built with pure HTML, CSS, and JavaScript.

The idea is simple:

**Send someone a link → they open it → the experience unfolds.**

---

## 🌌 What Is It?

After the Click turns an ordinary shared link into a small interactive experience.

Instead of sending someone a normal message, you can send them a personalized page with:

- ✨ Cinematic animations
- 🌌 Animated stars and glowing effects
- 🔐 Loading/decryption-style sequence
- 💎 Glassmorphism UI
- ⌨️ Typewriter messages
- 🎆 Particle effects
- 🪄 Interactive buttons
- 📱 Responsive mobile design
- ❤️ Small hidden details
- 🎭 Multiple experience types

---

## 🎭 Experience Types

The project currently supports:

| Type | Description |
|------|-------------|
| `friend` | A friendly personalized experience |
| `sister` | A message designed for a sister |
| `cousin` | A playful cousin experience |
| `birthday` | A birthday-themed experience |

---

## 🔗 Creating a Personalized Link

The easiest way is to use the built-in link generator.

1. Open `create.html`
2. Enter the person's name
3. Select an experience type
4. Generate the link
5. Copy the link
6. Send it to them

The generated URL contains the personalization information.

Example:


https://usmanwith1s.github.io/after-the-click/?name=Sara&type=friend

Another example:

https://usmanwith1s.github.io/after-the-click/?name=Ayesha&type=sister
